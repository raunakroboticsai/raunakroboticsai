## Flagship Builds

### 🧭 Autonomous 16×16 Maze Solver — *International, Estonia 2024*
Fully autonomous robot that explores, maps and solves an unknown 16×16 maze, then executes an optimised speed run.
- **Planning:** Flood-fill / Dijkstra / A* for exploration and shortest-path computation
- **Perception:** Distance-sensor fusion for wall detection and in-cell position correction
- **Control:** Closed-loop motion control with dynamic path correction

### ⚡ High-Speed Line-Following Robot — *National Benchmark*
- Custom 16-element IR sensor array for high-resolution line position estimation
- Tuned PID control with a fast feedback loop for stable cornering at high speed
- Lightweight chassis and motor selection optimised for acceleration
